## ⚙️ Setup Instructions

### Run Locally

1. Clone the repository:

```bash
git clone https://github.com/PushkarAdhikari/cursor-ui.git
```

2. Open project folder:

```bash
cd cursor-ui
```

3. Open `index.html` in browser  
(or use VS Code Live Server)
